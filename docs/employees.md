# 协作与责任边界

## 人工职责

开发者负责提供合法外部软件、私有凭据和目标环境，并执行真实环境、浏览器和许可证验收。私钥、API Key、令牌、原始日志、完整 prompt 和私有运行数据不得交给不需要它们的工具或写入仓库。

## 工程职责

| 领域 | 责任 |
|---|---|
| 架构与产品 | 维护产品边界、跨层契约、公开说明和验收缺口。 |
| 量子 | 维护量子输入审计、后端、产物和错误契约。 |
| 拓扑 | 维护参数化后端、组装、manifest 和产物校验。 |
| 模拟 | 维护 MD 协议、GROMACS、Packmol、阶段许可和恢复。 |
| 前端 | 维护状态消费、确认交互、运行助理和公开信息边界。 |
| 测试 | 维护回归、外部验收、测试台账和发布门禁。 |
| 环境与网关 | 维护外部工具注册、依赖边界与未来网关安全要求。 |

## 共同规则

1. LLM 不拥有 shell、任意文件写入或跨层工具权限。
2. 高影响动作必须经过服务端校验和明确用户确认。
3. 状态、产物、环境能力和错误分类由确定性代码产生；LLM 只能解释受限事实。
4. 新 run 不得复用其他 run 的输入、产物、阶段许可或聊天记录。
5. 公开界面不显示命令、绝对路径、密钥、原始日志或完整 prompt。
6. 代码、测试、责任文档和用户可见说明必须同步更新。
