# 托管 LLM 网关边界

托管网关不属于当前产品入口。当前应用只使用用户自配的 OpenAI-compatible LLM，不能通过环境变量、手工配置或兼容接口切换为托管模式。

若未来启用网关，必须先满足以下边界：

1. 浏览器、本地配置、prompt 和普通环境变量不能覆盖网关安全策略、模型映射、额度或认证。
2. BYOK 模式不得向网关发送用户 API Key、Base URL、完整 prompt 或用量明细。
3. 设备身份、管理员密钥、上游 Key、TLS 私钥、数据库和运行日志只可保留在部署机的私有存储中。
4. 网关必须提供认证、最小权限、速率/额度限制、审计、撤销、密钥轮换和多实例安全验证。
5. 真实部署、跨机器 TLS、上游调用和备份恢复必须独立验收，不能以本机 mock 或协议测试代替。

在这些条件满足前，网关相关代码和测试仅作为未来设计约束，不构成可用服务或发布承诺。
