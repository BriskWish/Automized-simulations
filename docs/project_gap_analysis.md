## 当前成熟方案

受支持的量子、拓扑和 GROMACS 组合必须从 Step 1 完成至 Step 10，最终状态为
`done`，并同时满足阶段许可、固定产物和 manifest/status 契约。这个标准只证明
工作流完整性，不构成科学体系预测或收敛质量结论。

当前测试台账为 `1968 pytest + 18 LLM = 1986`。

## 人工验收最小记录

每次目标机验收只记录当前版本标识、环境摘要、依赖可用性、执行方案、结果、公开错误摘要和脱敏证据位置。不得保存 API Key、令牌、完整 prompt、原始日志、绝对路径或私有运行目录。

## 非目标

- 科学体系性质、密度、结构、收敛质量或研究结论预测。
- G09 的可靠全链路承诺。
- 离子 OPLS 参数化及不同力场 family 混用。
- 远程 SSH/Slurm 执行、托管 LLM 网关和服务器控制。
- 作为公开产品能力的后处理与分析。
