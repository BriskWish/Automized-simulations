# 远程执行边界

远程 SSH、Slurm 和服务器控制不属于当前产品入口。当前方案只允许 `execution.md.backend=local`，前端不展示远程 profile、不读取远程凭据，也不连接或提交远端作业。

若未来启用远程执行，必须遵守：

1. 私钥、口令、完整主机名、绝对远端路径、命令和原始日志不得进入浏览器、LLM 或 run 公开状态。
2. 每个远端阶段必须由本地 run 的冻结配置、输入指纹和受限 profile 声明；禁止任意 shell 或路径传入。
3. EM、EQ、PROD 仍按本地阶段许可串行提交。远端进程或队列成功不替代本地产物下载和验收。
4. 停止、断连、产物同步、哈希不一致、checkpoint 恢复和调度状态必须有受管审计与独立测试。
5. SSH 直连和 Slurm 提交应使用最小权限账户与专用工作目录，不在登录节点直接运行生产 `mdrun`。

在完成独立安全设计、目标环境验证和发布门禁前，远程执行不得出现在产品说明或用户操作路径中。
