# 模拟层

模拟层将当前 run 的已验证拓扑转为 Packmol 初始盒、GROMACS EM、三点式退火 EQ 和 PROD。它只接受当前 run 内通过契约的输入，并以阶段许可控制下游执行。

## 协议

```text
拓扑与坐标 -> MDP -> Packmol -> EM accepted -> EQ accepted -> PROD completed
```

`config.json.simulation.protocol` 定义 MD 参数。默认时间步长为 `0.001 ps`；EQ 使用高温、过渡温度和目标温度组成的三点式退火；PROD 必须从已验收的 EQ checkpoint 连续启动。协议或输入指纹变化时，受影响阶段必须重新生成，不能 append 到不匹配轨迹。

## 阶段产物与许可

| 阶段 | 许可 | 必需产物 |
|---|---|---|
| EM | `em_accepted` | `.tpr`、`.gro`、`.xtc`、`.edr` |
| EQ | `eq_accepted` | `.tpr`、`.gro`、`.xtc`、`.edr`、`.cpt` |
| PROD | `prod_completed` | `.tpr`、`.gro`、`.xtc`、`.edr`、`.cpt` |

所有产物必须来自当前受管调用、非空并满足阶段校验。文件存在不等于许可已获得。

原样 `/resume` 沿用原工程稳定配置，不应用新参数。每个实际步骤启动前校验输入 SHA-256；
非空但变化的文件须由用户通过 `/inputs` 明确声明，LLM 决定具体消费步骤范围，服务器检查格式并绑定新版本。
来源豁免不补造上游许可，也不放宽 EQ 覆盖、时间轴或数值判据。完整规则见 [`run_assistant.md`](run_assistant.md)。

重放的旧产物在工作开始前归档至 `old/`，新准出必须对应本轮执行编号。PROD 只有阶段契约和续接文件哈希匹配
（或明确声明指定文件版本）才能保留 checkpoint 集合并尝试 append；GROMACS 内部一致性检查仍有效。
其他重放先归档再重建，EM/EQ 不新增 checkpoint 续接。报错后确认新方案或新参数创建独立子工程，不能覆盖父工程重跑。

## 建盒与预检

建盒前校验 `residues`、`topol.top`、ITP 与坐标的一致性。初始体积默认按拓扑质量和 `0.7 g/cm3` 计算，显式 `box_size` 优先。Packmol 输入必须声明周期边界，输出 PDB 的 `CRYST1` 必须与请求盒矢量一致。

Packmol、grompp 和 mdrun 失败分别保留受限类别。动态加载器、ABI 或依赖库问题为 `runtime_unavailable`，不尝试通过改动密度或 MDP 修复。`grompp` 默认拒绝 warning；仅当输出中只有一个 Ewald 净电荷 warning，且可解析的总电荷满足 `abs(total_charge) <= 0.15 e` 时可受控使用一次 `-maxwarn 1`。允许区间为 `[-0.15 e, +0.15 e]`，包含两个端点；单位为电荷 `e`，不是能量 `eV`。缺少可解析电荷、超过阈值、伴随其他 warning 或受控重试失败时仍拒绝。

该白名单用于参数化电荷的累计舍入，不改写电荷或授予阶段许可，也不替代配置阶段的
`charge_imbalance` 门禁。原始量子输入所声明的非中性体系仍须用户明确补偿或非中性策略，
详见 [`ERR_WARN_Build.md`](ERR_WARN_Build.md) 与 [`quantum.md`](quantum.md)。

## EQ 与 PROD 验收

EQ 使用 `eq-final-1ns-five-blocks-v1` 规则：在最终目标温度保持段的最后 1 ns 检查五段真实覆盖，再对完整窗口的原始样本计算温度均值与势能归一化线性斜率。温度均值容差默认 5 K，势能阈值沿用配置；未通过时不得进入 PROD。这是既定统计规则的可靠执行，不是科学平衡性的充分证明。PROD 检查正常结束、轨迹帧、EDR、checkpoint 与强制产物完整性。

数值有效性是 EQ 放行的强制前置条件。验收窗口、温差与势能斜率阈值、目标温度及保持时长元数据必须有限；成功提取的
温度、势能、密度、压力序列，其时间和数值都不得包含 `NaN`、`+Inf`、`-Inf`。均值、方差、
斜率等统计运算发生溢出或产生非有限结果时同样失败，不保存非有限统计量，也不授予 EQ 许可。
密度与压力仍不新增收敛阈值；这两个可选能量项无法提取时保留诊断说明，不单独阻断。

`md.eq.acceptance.window_ns` 固定为 1.0 ns，其他值在配置校验时拒绝，不再允许缩短窗口以放行。
最终目标保温段默认 2.0 ns，可以改变，但不足以容纳完整 1 ns 时不能验收；PROD 的至少 2 ns 下限与此无关。

| 统计标签 | 相对已核验 EQ 终点的区间（ns） |
|---|---|
| 倒数 0.8 ns | `[-1.0, -0.8)` |
| 倒数 0.6 ns | `[-0.8, -0.6)` |
| 倒数 0.4 ns | `[-0.6, -0.4)` |
| 倒数 0.2 ns | `[-0.4, -0.2)` |
| 结束 0 ns | `[-0.2, 0.0]` |

- 读取实际 EQ MDP 的 `dt`、`nsteps`、`tinit`、`init-step`、`nstenergy` 和退火时间/温度，核对 manifest 时间元数据；最后两退火点必须对应目标温度，整个窗口必须属于本 EQ 的最终保持段。
- `eq.log` 必须包含最终步后的正常结束标记，实际末步和末时刻须与协议一致；即使出现 `Finished mdrun`，提前停止也不能通过。能量末时刻必须匹配协议终点，不按短文件的最后时间重设窗口。
- 按 `dt × nstenergy` 逐点核对窗口内预期采样网格，并核对末步额外输出；要求覆盖全部预期样本，每段至少两个有效样本。首尾缺失、任一缺段、内部缺点、额外/偏离网格时间、乱序或重复均失败。只允许时间戳精度容差，不排序、去重、插值或豁免缺点。
- 五段各用全部原始样本，前四段左闭右开，最后一段含终点，边界只计入一次；分段均值是审计和展示依据，不增加分段温度/势能阈值，也不替代完整窗口统计。密度/压力不新增收敛阈值，无法提取的可选项仍不阻断；一旦成功提取，数值和时间证据同样必须有效。
- run 私有验收详情保存规则标识、正常结束证据、预期/观测窗口、采样频率、各段计数与均值和整体统计。PROD 除 `accepted` 外还要求新规则的完整证据，且 EQ MDP、TPR、坐标、EDR、日志、checkpoint、温度与势能 XVG 的登记指纹未变；旧许可不会静默升级或回写，缺证据时须按现有确认流程重新验收 EQ。

当前代码对真实 EQ 产物隔离副本的受管复验和脱敏结果见 [`g09_eq_coverage_20260906.json`](../tests/reports/audits/g09_eq_coverage_20260906.json)；复验未启动新模拟，也未修改原 run 的许可。

错误对外归类为输入契约、引擎失败、数值不稳定、平衡未通过和恢复冲突。自动恢复只允许白名单工具和受限次数；温度、时长、压力耦合、输出精度和协议变更必须先取得用户确认。

EQ 待确认恢复方案固定包含“问题”“当前步调参重试”“打回前序流程重试”和逐点“证据”。当前步只能从第 9 步重新验收；打回前序流程只允许经证据支持后从第 7 步 Packmol 重建。两条路径均为高风险科学协议变更，必须人工审核和明确确认；EM 等低风险、无协议变更的受控重试仍按既有恢复策略执行。`ErrorKind=unknown` 不得触发默认参数调整，而是升级为联网检索申请/人工审核，保持配置和阶段许可不变。

## 运行与停止

GROMACS 由独立受管进程组执行。`mdrun` 保留长任务时限和 `SIGINT -> SIGTERM -> SIGKILL` 停止升级，以优先保留 checkpoint。

除 `mdrun` 外，`grompp`、`energy`、`check`、`trjconv`、建盒与可视化 `editconf` 以及内部分析命令共用辅助执行器：单次执行最多 20 秒，调用方指定更短时限时保留更短值；只有超时才允许再次启动同一命令，总计最多 3 次（含首次），即最多 60 秒执行预算，而非三次合计 20 秒。版本和依赖探针保留原有不超过 20 秒的更短时限与单次调用。

辅助命令不承担 checkpoint 保存，超时或用户停止时直接向受管进程组发送 `SIGKILL`；每次另有最多 2 秒的有界管道排空与子进程回收。只有前一次已回收后才允许重试，回收失败、非零退出和用户停止均不触发自动重试；轮询等待不计作新的命令尝试。每次执行只写一组开始/结束审计，最终超时向上层抛出，不会被轮询循环重新捕获。

停止不是自动修复触发条件，最终状态必须为 `aborted`。私有生命周期记录保存信号和退出事实，公开状态只显示脱敏摘要。

## 后处理边界

后处理只能读取同一 run 的已完成 PROD 产物，结果写入独立 `analysis/<analysis_id>/`，不得修改 MD 输入、原始轨迹或拓扑。它不是当前公开主流程能力，也不由 LLM 生成科学结论。
