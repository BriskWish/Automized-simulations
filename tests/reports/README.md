# 测试报告目录

本目录只保存测试拥有的脱敏证据和自动生成的测试目录，不承载产品设计、问题台账或发布叙事。

`test_case_catalog.md` 由收集脚本生成，反映当前 pytest 和 LLM 场景。受控报告只记录测试范围、环境能力、配置散列、阶段结果、产物散列和验收结论；不得写入工作区路径、命令输出、原始日志、`.env`、API Key、令牌或凭据。

发布检查在隔离副本中执行 Python 打包、测试、编译和 mock-eval 门禁，不影响活动模拟。Vendor staging 只能复制许可清单中的文件，验证时不执行二进制；设计、规范、计划和缺口统一维护在 `docs/`。
